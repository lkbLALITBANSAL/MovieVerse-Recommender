# MovieVerse React + SBERT

This project converts the Streamlit MovieVerse frontend into a React frontend.

Architecture:

React
  -> FastAPI
  -> movies_API.pkl
  -> similarity_API.pkl
  -> posters_API.pkl

The similarity matrix should be generated by your SBERT notebook.

## 1. Backend

Copy your existing pickle files:

```text
movies_API.pkl
similarity_API.pkl
posters_API.pkl
```

into:

```text
backend/data/
```

Then:

```bash
cd backend
pip install -r requirements.txt
uvicorn main:app --reload
```

## 2. Frontend

Open a second terminal:

```bash
cd frontend
npm install
npm run dev
```

Open:

http://localhost:5173

## Search

Typing `dhu` calls:

```text
GET /search?q=dhu
```

The backend returns matching movies. Clicking a result loads:

```text
GET /movies/{id}
GET /recommend/{id}
```

The home page also calls:

```text
GET /top-rated
```

so the Top Rated Movies section is always displayed.

## Production

Set:

```text
VITE_API_URL=https://your-backend-url
```

before building the React frontend.
